## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/ianniboss/MarioPortfolio.git
   cd MarioPortfolio
   ```

2. Navigate to frontend directory
   ```bash
   cd frontend
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Run development server
   ```bash
   npm start
   ```

5. Open your browser
   Navigate to http://localhost:3000

### Build for Production

```bash
npm run build
```
